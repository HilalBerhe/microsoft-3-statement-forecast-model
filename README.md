# Microsoft 3-Statement Forecast Model

## Project Overview

This project is a simplified 3-statement financial forecast model for Microsoft built in Excel. The model uses historical financial statement data to forecast Microsoft’s income statement, balance sheet, cash flow statement, working capital, property and equipment, debt, and cash position from 2026 to 2030.

The purpose of this project is to practice core financial modeling skills, including financial statement linking, forecasting assumptions, supporting schedules, and Excel-based model presentation.

## Model Structure

The model includes the following sections:

1. Assumptions
2. Income Statement
3. Balance Sheet
4. Cash Flow Statement
5. Supporting Schedules
6. Charts and Graphs

## Key Features

- Historical financial statement setup from 2022 to 2025
- Forecast period from 2026 to 2030
- Revenue forecast based on revenue growth assumptions
- COGS forecast based on COGS as a percentage of revenue
- SG&A forecast based on percentage of revenue
- Tax forecast based on earnings before tax
- Working capital schedule using accounts receivable, inventory, and accounts payable
- Depreciation schedule using PPE, capital expenditures, and depreciation
- Debt schedule using opening debt, debt issuance/repayment, and closing debt
- Cash flow statement forecast using operating, investing, and financing cash flow
- Balance sheet cash linked from the closing cash balance
- Summary charts for revenue, gross profit margin, operating cash flow, investing cash flow, and financing cash flow

## Forecast Assumptions

The forecast uses simplified assumptions based on historical averages and trend analysis, including:

- Revenue growth
- COGS as a percentage of revenue
- SG&A as a percentage of revenue
- Depreciation and amortization as a percentage of PPE
- Tax rate
- Accounts receivable days
- Inventory days
- Accounts payable days
- Capital expenditures
- Debt issuance/repayment
- Equity issuance/repayment

## Notes and Limitations

This is a simplified practice model and does not include every line item from Microsoft’s full financial statements. Some detailed items such as other current assets, intangible assets, deferred revenue, other liabilities, accumulated other comprehensive income, and other equity adjustments are not modeled separately.

The purpose of the model is to demonstrate the core mechanics of a 3-statement forecast model, including how assumptions flow through the income statement, supporting schedules, cash flow statement, and balance sheet.
